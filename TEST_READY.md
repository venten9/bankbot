## 3. Financial & Concurrency Integrity Verification

1. **Zero Overdraft Guarantee**: Verified by `test_ten_concurrent_transfers_overdraft_stress` and `test_twenty_concurrent_transfers_competing_to_zero`. When 10 concurrent tasks attempt to debit 200.00 ₽ each from an account with only 500.00 ₽, exactly 2 succeed and 8 fail with `InsufficientFundsError`. The balance never drops below 0.00 ₽.
2. **Double-Entry Ledger Invariant**: Verified by `test_transfer_creates_balanced_ledger_entries`. Every transfer produces balanced `DEBIT` and `CREDIT` entries in `ledger_entries`, conserving total currency in the system.
3. **Anti-Duplication Payout Guard**: Verified by `test_duplicate_interest_payout_prevention`. High-frequency double-tap interest payout requests execute once and reset the interest accumulator, with the second request yielding 0.00 ₽.
4. **Offline Isolation**: All tests run without internet connection, live Telegram tokens, or external API endpoints using mock bot harnesses and SQLite WAL mode engines.
